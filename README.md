# SayakaCleaner releases

Official downloads of SayakaCleaner for macOS, made by Genjux.

Website: https://sayakacleaner.pages.dev

Download the latest `.dmg` from [Releases](https://github.com/PetrGuan/SayakaCleaner-releases/releases/latest). Every build is signed with a Developer ID certificate and notarized by Apple.

- Requires macOS on Apple silicon or Intel (universal app).
- Support: genjux1024@gmail.com

This repository holds release files only; it does not contain source code.
